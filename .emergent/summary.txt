<product_requirements>
The IT Signature ERP is a multi-tenant SaaS application designed for employee attendance and HR management with a responsive UI/UX. It features a dashboard with clickable metrics, comprehensive employee management (including profile pictures and flexible working times), and role-based access control (Admin, Manager, Staff, Employee). Authentication is OTP-based via multiple Sri Lankan SMS gateways. Core modules include Leave Management, Monthly Payroll, and Loan/Increment tracking. Company settings enable configuration of work calendars, office timings, and SMS preferences. A Super Admin manages independent companies, each with custom branding and detailed activity logging. Recent major additions include Super Admin impersonation (with configurable read/write access), scheduled salary increments affecting future payrolls, and a detailed payroll generation system that accounts for month-specific effective salaries, late deductions, and basic loan management. Manual attendance also received enhancements for optional check-out, date validation, duplicate prevention, and edit history. UI/UX improvements targeted menu organization, font sizes, and filter label reduction.
</product_requirements>
